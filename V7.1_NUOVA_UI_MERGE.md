# MAIA V7.1 — New UI Merge

This build keeps the complete V7.1 Personal Memory Hardening codebase and integrates the visual/UI improvements observed in the AI Studio exported project.

## Preserved from V7.1 Fix
- MAIA Core and orchestrator
- Intent Engine / semantic classifier / target resolver
- Action router and executor
- Memory, Notes and Reminder capabilities/managers
- Session context and verification/recovery
- Safety and confirmation logic
- Model router / Gemini provider architecture
- Existing tests and documentation

## Integrated from the AI Studio UI project
- New compact MAIA header and visual identity
- Notes / Promemoria / Memoria shortcut buttons with live counts
- Shortcut routing into the corresponding control-panel section
- New neural core visual animation
- New Android-style status bar with MAIA core status
- New chat bubble styling
- New overall dark indigo/violet visual base
- New welcome message

## Important integration detail
The shortcut section is explicitly synchronized with the settings sheet, so opening Promemoria or Memoria does not fall back to the Notes section.

No AI Studio-generated simplified Core/services were copied into this build.
