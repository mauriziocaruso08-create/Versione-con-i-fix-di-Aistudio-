# MAIA V7.1 — Personal Memory Hardening

## Decision
Personal notes are part of MAIA long-term UserMemory and are now explicitly visible in the Memory menu as **Personali**. Operational notes remain a separate **Note** section.

## Storage ownership
- Name/city/preferences/interests/projects/personal notes: `maia_user_memory_v1` via MAIA Memory Engine.
- Operational notes: `MaiaNote` / NotesManager.
- Reminders: ReminderManager.
- Gemini is not the persistence layer and does not decide whether a local memory write occurred.

## Automatic memory policy
- Explicit profile statements (name/city) are high-confidence and can be persisted directly.
- Explicit preference statements are persisted directly by MemoryCapability/PreferenceManager.
- Stable interests/projects can be persisted when they match high-confidence patterns.
- Ambiguous habits or potentially useful personal facts require confirmation before persistence.
- Temporary/casual statements are rejected from automatic long-term memory.
- Sensitive credentials and similarly sensitive data are rejected.

## UI
The Memory menu now distinguishes:
1. Preferenze
2. Interessi
3. Progetti
4. Personali (UserMemory notes)
5. Note (operational notes)
6. Promemoria

This is intentionally a small UI extension, not a redesign.
