# MAIA V7.1 — Intent Understanding 2.0 / Personal Memory Hardening

This patch moves explicit first-person personal facts into a MAIA-Core-owned memory path.

## Principle

Personal memory is determined from semantic structure, not a vocabulary of specific attributes.
The current deterministic parser recognizes the grammatical shape `possessive attribute + copula + value`, so examples such as:

- `Il mio colore preferito è il verde`
- `La mia squadra preferita è il Milan`
- `Il mio animale preferito è il gatto`

all become `CREATE / MEMORY / personal_facts` with a generated semantic key.

## Pipeline

`Input -> Intent Understanding -> PERSONAL FACT -> MemoryCapability -> localStorage -> Verify -> Response`

Gemini is not required to decide whether these explicit facts should be stored.

## Storage

Personal facts are stored separately from behavioral preferences under `UserMemory.personalFacts`. This prevents facts such as favorite color from being misclassified as assistant-response preferences.

## Regression

`test_personal_memory_intent_v2.ts` checks generic attribute extraction and rejects a temporary/casual statement.
