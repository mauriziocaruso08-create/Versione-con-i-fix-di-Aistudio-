# MAIA V6.4 — Contextual Follow-up Stabilization

## Scope
Stabilization only. Existing UI and MAIA architecture preserved.

## Fix
Added deterministic contextual READ handling for natural follow-ups that omit the entity name, including:
- "Fammi vedere quella"
- "Mostra quello"
- "Apri la seconda"
- "Leggimi il primo"

The classifier now produces a local READ intent with PRONOUN/ORDINAL target and uses SessionContext + TargetResolver for resolution.
