# MAIA V6.2 — Stabilization Notes

## Fix: stale in-flight chat responses

A request sent to the AI provider can outlive the visible chat session. If the user starts **Nuova chat** while that request is still running, the old response must not be appended to the new conversation.

V6.2 adds a monotonic chat-session generation guard:

- every new chat invalidates all previous in-flight requests;
- each request captures the generation active when it started;
- provider replies from an older generation are discarded;
- provider errors from an older generation are discarded as well;
- Memory, Notes and Reminders remain untouched by New Chat.

This is a UI/session integrity fix and does not change MAIA Core, the Intent Engine, Model Router, Gemini integration, or persistent memory architecture.
