# MAIA V7.1 — Context & Intent Hardening

This patch extends the V7.1 roadmap baseline after the torture-test cycle.

## Included

- Conversational leading connectors such as `E ...` are normalized before semantic intent classification.
- Natural questions about a specific reminder (`A che ora devo ...`, `Quando devo ...`) can remain local when reminder context is active.
- Generic destructive deletion is safety-first: with multiple candidates MAIA asks which item to delete instead of inheriting a selected item.
- Named notes preserve an optional title separately from their content.
- Memory responses convert user-authored first-person preference wording to direct second-person wording without modifying stored data.
- Existing name/profile behavior remains unchanged.
- Added/strengthened deterministic regression coverage for these cases.

## Roadmap alignment

This is a hardening slice of the existing pipeline:

`Input -> SessionContext -> Semantic Intent -> Target Resolution -> Safety -> Capability -> Verification -> Response`

No new provider dependency is introduced.
