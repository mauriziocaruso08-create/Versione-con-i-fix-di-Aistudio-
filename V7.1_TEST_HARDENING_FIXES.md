# MAIA V7.1 — Test Hardening Fixes

Applied after AI Studio validation of the Roadmap v2 build.

## Fixed
- Direct personal-memory questions are routed to `MemoryCapability` instead of the provider model.
  - name / city queries
  - specific personal facts such as favorite color / animal
  - `Cosa ricordi di me?`
  - contextual `E qual è il mio?` after a memory write
- Direct profile statements such as `Mi chiamo Maurizio` are handled locally and persisted into `userName`.
- Combined profile statements (`Mi chiamo X e vivo a Y`) update both profile fields locally.
- Settings profile inputs now synchronize when the underlying memory changes.
- Reminder update parsing extracts destination date/time before generic colon parsing, preventing `11:00` from becoming new text `00`.
- Standalone reminder pronouns such as `Spostalo...` are normalized to contextual pronoun targets.
- Natural note syntax `Crea una nota chiamata X con scritto Y` now stores the actual note content `Y` (the current note schema has no separate title field).

## Validation note
Full dependency-based TypeScript build could not be certified in this environment because project dependencies are not installed. A targeted TypeScript parse check found no syntax errors in the modified source files; missing-module diagnostics are environmental.
